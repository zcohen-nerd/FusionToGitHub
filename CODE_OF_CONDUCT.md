# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone taking part in its issues, pull requests and other spaces is expected
to follow it: be respectful and welcoming, give and accept constructive
feedback gracefully, and focus on what is best for the people using and
building the project. Harassment and personal attacks are not accepted.

## Reporting

If you experience or witness unacceptable behaviour, report it to the
maintainer (zcohen-nerd on GitHub) privately, or with GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature. Reports are handled confidentially.

## Enforcement

The maintainer may remove, edit or reject comments, commits, code, issues and
other contributions that don't follow this Code of Conduct, and may
temporarily or permanently ban anyone whose behaviour is inappropriate, as
described in the Contributor Covenant's enforcement guidelines.
