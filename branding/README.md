# Branding: the Push to GitHub icon

## The artwork

An isometric cube with sharp edges and three blue faces, on a navy square,
with an orange three-node branch on its right face: a design (the cube)
with a history (the branch).

| Element | Colour |
|---|---|
| Background | `#071B41` (navy) |
| Top face | `#5BC9F2` |
| Left face | `#1F8BC2` |
| Right face | `#023F65` |
| Branch | `#FD9815` (orange) |
| Node centres (large sizes) | `#FFFFFF` |

**Provenance.** The maintainer approved a raster master,
`Assets/Branding/Icon-Master.png` (1254 × 1254 px). It is kept outside the
repository (untracked) at the maintainer's choice. The vector version here
was redrawn from it as clean geometry for 0.7.0: flat colours instead of the
master's slight gradients, and exact isometric edges. Proportions, colours
and layout follow the master. It contains no GitHub, Git or Autodesk marks
(audit COMP-02: the earlier icon embedded GitHub's Invertocat).

The icon is part of this project and is distributed under the project's
licence (see `LICENSE`).

## Files

Everything is generated by `scripts/make_icons.py` from one drawing. Edit
the drawing there, never the outputs.

| File | Size | Used for |
|---|---|---|
| `branding/icon.svg` | vector | The master vector artwork |
| `branding/icon-small.svg` | vector | The simplified drawing used at 16 and 32 px |
| `src/AddInIcon.svg` | vector | Fusion's Scripts and Add-Ins list (manifest `iconFilename`) |
| `src/resources/16x16.png`, `16x16@2x.png` | 16, 32 px | Toolbar button (small) |
| `src/resources/32x32.png`, `32x32@2x.png` | 32, 64 px | Toolbar button (large); `32x32@2x.png` is also the Community Store icon |
| `branding/png/icon-120.png` | 120 px | Autodesk App Store icon (needs at least 120 × 120) |
| `branding/png/icon-256.png`, `icon-512.png` | 256, 512 px | Documentation, store listings, social preview |

The four `src/resources/` files are in the release ZIP
(`Push_To_GitHub/resources/`); `scripts/package.py` lists them, and the add-in
passes that folder to `addButtonDefinition`.

### Small sizes

At 16 and 32 px the full drawing's thin branch and white node centres blur
into the cube, so those sizes use a **small** drawing: the cube is 16 %
larger, the branch is thicker, and the nodes are solid orange. It was checked
at its real pixel size on a light (`#F2F2F2`) and a dark (`#2B2B2B`)
background, the two toolbar themes. Because the icon has its own navy
square, it doesn't depend on the theme behind it, and the orange branch stays
visible on both. How it looks in Fusion's own toolbar is checked in the
manual checklist (`tests/MANUAL_CHECKLIST.md`, item U3); that hasn't been done yet.

## Regenerating

```
python scripts/make_icons.py          # write every file (about 15 s)
python scripts/make_icons.py --check  # CI: fail if a committed file differs
```

Standard library only; no Pillow or Inkscape. The PNGs are rendered with 4 × 4
supersampling and written without metadata, so the same script gives the
same bytes on every machine. `tests/unit/test_ux_helpers.py` runs the check
and confirms the sizes, and that the SVGs contain no embedded raster image.
